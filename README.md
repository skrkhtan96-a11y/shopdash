# تطبيق محاسبة الأعمال المتكامل — الربط الفعلي مع سلة (Salla Partner Integration)

تطبيق ويب متكامل (Full-Stack Web App) مبني باستخدام **Node.js** و **Express** وقاعدة بيانات **SQLite** مدمجة، مصمم لربط وتتبع معاملات متجرك في سلة بشكل حقيقي وتلقائي عبر بروتوكول **OAuth 2.0** والـ **APIs الرسمية من سلة**، مع إدارة متقدمة للمصروفات التشغيلية والأرشفة الشهرية.

---

## 📁 هيكلية ملفات التطبيق الجديد

```text
d:/sho10/
├── database.db             # قاعدة بيانات SQLite (تنشأ وتدار تلقائياً)

├── server.js               # خادم Backend الرئيسي (Express) لمعالجة التصاريح وجلب الـ APIs
├── package.json            # ملف الاعتمادات والمكتبات
├── .env                    # ملف الإعدادات والمفاتيح السرية الحساسة (يتطابق مع بوابة شركاء سلة)
├── .env.example            # نموذج استرشادي للملف البيئي
└── public/                 # مجلد الواجهة الأمامية للمتصفح
    ├── login.html          # صفحة تسجيل الدخول المتوافقة مع هوية سلة وشركائها
    ├── index.html          # لوحة التحكم الرئيسية المربوطة بالـ APIs
    ├── css/
    │   └── style.css       # ملف التنسيق الأنيق الموحد
    └── js/
        └── app.js          # منطق الواجهة الأمامية والاتصال بالخادم وجلب البيانات الحقيقية
```

## ⚡ خطوة بخطوة: كيفية تشغيل التطبيق محلياً

### 1. تثبيت الاعتمادات
تأكد من تنزيل الحزم البرمجية بالكامل بتشغيل الأمر التالي في مجلد المشروع:
```bash
npm install
```

### 2. إعداد المتغيرات البيئية (`.env`)
قم بنسخ ملف `.env.example` وتسميته بـ `.env` ثم تعبئته بمفاتيح التطبيق الخاص بك من بوابة شركاء سلة:
```env
PORT=3000
SESSION_SECRET=salla_dashboard_secret_key_12345

SALLA_CLIENT_ID=أدخل_Client_ID_الخاص_بك
SALLA_CLIENT_SECRET=أدخل_Client_Secret_الخاص_بك
SALLA_REDIRECT_URI=http://localhost:3000/callback
```

> 💡 **ملاحظة:** التطبيق مهيأ بـ **نمط المحاكاة التلقائي (Simulated Mode)**. في حال لم تقم بتعبئة المفاتيح، سيعمل التطبيق كنسخة تجريبية مع لوحة تحكم كاملة وبيانات وهمية متقدمة لتجربة الواجهة بحرية، ولن يقيد عملك.

### 3. تشغيل التطبيق محلياً
قم بتشغيل الخادم المحلي باستخدام الأمر التالي:
```bash
npm start
```
سيفتح لك التطبيق على الرابط المحلي: **`http://localhost:3000/`** (سيقوم تلقائياً بتوجيهك لصفحة `login.html`).

## ☁️ دليل الرفع للاستضافة (Deployment Guide)

يمكنك رفع هذا التطبيق على أي سيرفر أو استضافة تدعم Node.js مثل:
* **Hostinger / GoDaddy (استضافات المشتركة لـ Node.js)**
* **VPS (خوادم افتراضية خاصة مثل DigitalOcean, AWS, Linode)**
* **منصات السحابية (Render, Heroku, Vercel)**

### 🚀 خطوات الرفع العامة:
1. **رفع الملفات**: ارفع كافة مجلدات المشروع ما عدا مجلد `node_modules` (حيث سيتم تثبيته تلقائياً على خادم الاستضافة).
2. **تثبيت الحزم على الاستضافة**: عبر لوحة التحكم للاستضافة أو اتصال SSH، قم بتشغيل `npm install`.
3. **ضبط الـ Redirect URI**:
   - تأكد من تغيير `SALLA_REDIRECT_URI` في ملف `.env` على الاستضافة ليتطابق مع رابط موقعك الفعلي (مثال: `https://yourdomain.com/callback`).
   - قم بتحديث حقل الـ **Redirect URI** داخل لوحة تحكم تطبيقك في **بوابة شركاء سلة (Salla Partners)** ليتطابق تماماً مع الرابط أعلاه.
4. **تفعيل وضع التشغيل**: تأكد من تعيين ملف البدء ليكون `server.js` وتشغيله بوضع الإنتاج (Production).

## 🛠️ كيفية التسجيل في بوابة شركاء سلة والحصول على المفاتيح

1. قم بإنشاء حساب في [بوابة شركاء سلة (Salla Partners Portal)](https://salla.partners/).
2. انتقل لقسم **تطبيقاتي (My Apps)** واضغط على **إنشاء تطبيق جديد (Create New App)**.
3. قم بتعبئة بيانات التطبيق الأساسية.
4. في إعدادات التطبيق الفنية (Technical Settings):
   - قم بتعيين الـ **Redirect URI** إلى الرابط المحلي للتجربة: `http://localhost:3000/callback` (وعند الرفع للاستضافة قم بإضافة رابط موقعك).
   - قم بتفعيل الصلاحيات (Scopes) التالية:
     * `offline_access` (أهم صلاحية لتحديث الاتصال تلقائياً دون انقطاع).
     * `profile`
     * `orders` (قراءة).
     * `products` (قراءة).
     * `customers` (قراءة).
5. احفظ الإعدادات، وانسخ كل من `Client ID` و `Client Secret` وضعهما في ملف `.env` الخاص بك.
6. افتح لوحة التحكم واضغط على "تسجيل الدخول وربط متجر سلة" ليتم ربط متجرك الفعلي بنجاح وسحب البيانات تلقائياً!
